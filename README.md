## 📖 درباره پروژه

«سامانه هوشمند مدیریت مدرسه» یک نرم‌افزار وب **آفلاین** است که برای رفع مشکلات مدیریتی مدارس، به‌ویژه مدارس مناطق محروم و روستایی، طراحی شده است.

این پروژه به سه نقش اصلی اجازه می‌دهد تا بدون نیاز به اینترنت یا سرور، تمام کارهای مدیریتی مدرسه را انجام دهند:

- 👔 **مدیر** — ساخت معلم، نظارت بر کلاس‌ها، گزارش جامع
- 👨‍🏫 **معلم** — ساخت کلاس، ثبت نمره، حضور و غیاب، تکالیف و رویدادها
- 👨‍🎓 **دانش‌آموز** — مشاهده نمرات، تکالیف، برنامه روزانه و کارنامه

> ⚡ نکته متمایز: این پروژه **بدون دسترسی به لپ‌تاپ یا کامپیوتر**، تنها با یک گوشی اندروید و در مدت **سه ماه** ساخته شده است.

---

## ✨ ویژگی‌های کلیدی

### 👔 پنل مدیر
- ساخت معلم‌های جدید با نام کاربری و رمز اختصاصی
- مشاهده لیست کامل معلم‌ها و کلاس‌ها
- گزارش جامع با میانگین نمرات و درصد حضور هر کلاس
- پشتیبان‌گیری کامل از تمام داده‌ها (فایل JSON)
- فعال‌سازی از طریق کد اشتراک سالانه

### 👨‍🏫 پنل معلم
- ساخت کلاس با نام و درس
- افزودن دانش‌آموز به صورت تکی یا گروهی
- تولید خودکار رمز یکتا برای هر دانش‌آموز
- ثبت نمره با نمایش خودکار قبول/مردود
- حضور و غیاب روزانه با دکمه‌های سریع (حاضر / غایب / مرخصی)
- سیستم تشویق و تنبیه با امتیاز مثبت و منفی
- گزارش‌گیری روزانه، ماهانه و کل دوره
- محاسبه خودکار درصد حضور
- یادداشت داخلی برای هماهنگی
- پشتیبان‌گیری جداگانه برای هر کلاس

### 👨‍🎓 پنل دانش‌آموز
- نمایش نمرات به صورت شخصی (فقط نمرات خودش)
- محاسبه خودکار معدل
- برنامه روزانه
- لیست وظایف با امکان تیک زدن
- بازیابی گزارش از معلم
- امکان تعیین عکس پروفایل

### 🌐 امکانات عمومی
- 🎨 رابط کاربری راست‌به‌چپ (RTL) با تم تاریک
- 📱 طراحی واکنش‌گرا (گوشی، تبلت، کامپیوتر)
- 🖨️ قابلیت چاپ گزارش‌ها
- 📴 کاملاً آفلاین — بدون نیاز به اینترنت
- 📖 مودال راهنما با لینک ویدیوهای آموزشی
- 💾 پشتیبان‌گیری سلسله‌مراتبی (مدیر → معلم → کلاس → دانش‌آموز)
